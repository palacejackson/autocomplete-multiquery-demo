# Autocomplete Multiquery Demo

A demonstration of Algolia's autocomplete functionality with multi-query support.

## Getting Started

### Installation

```bash
npm install
```

### Running

Open `index.html` in your browser or start a local development server:

```bash
npm start
```

## Files

- `index.html` - Main HTML file
- `main.js` - JavaScript logic
- `styles.css` - Styling
- `package.json` - Project dependencies and scripts
